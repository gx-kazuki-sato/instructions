各文書の「作成の来歴」に、依頼日時・話題・ワークスペース・作成モデルと確認根拠を記載します。使うときは、その本文と対象リポジトリ・ブランチ・許可範囲をAIに渡してください。

## 保存基準

次の説明を、推測せずに埋められる指示書だけを保存します。

> 私が○年○月○日に、XXXに関するチャット（ワークスペースZZZ）で、モデルYYYに対して作らせたもの。

- 元の作成依頼の日時とタイムゾーン、チャットの話題と識別情報、ワークスペース、実際に文書を生成したモデルを確認します。依頼と保存する本文が対応している証拠も必要です。
- いずれかを確認できなければ、保存・掲載しません。ファイル名、更新日時、Gitのコミット日時、希望されたモデル名、現在のモデルから来歴を推測しません。
- 元の来歴が不明な規約を新たに汎用化しても、その再編集日・モデルで元の来歴を代用しません。汎用化した文書を、過去にユーザーが作らせた原本として扱いません。
- ファイル名は原則 `YYYY-MM-DD-<記録で確認した作成モデル>-<内容が分かる名前>.md` とし、日付は元の作成依頼日の日本時間を使います。後日の改名・追記は、元の作成と区別して記録します。
- 公開する根拠は必要最小限とし、会話ログ全文、認証情報、非公開の業務情報、個人のローカル絶対パスを転載しません。
